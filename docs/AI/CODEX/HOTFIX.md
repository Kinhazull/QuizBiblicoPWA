## Restrições

- Alterar apenas o necessário.
- Não incluir melhorias paralelas.
- Não fazer migration, deploy, push ou merge sem autorização.
- Preservar rollback simples.
- Adicionar teste de regressão quando possível.

## Procedimento

1. Confirmar causa.
2. Definir correção mínima.
3. Implementar.
4. Validar.
5. Relatar risco residual.
6. Preparar rollback.
