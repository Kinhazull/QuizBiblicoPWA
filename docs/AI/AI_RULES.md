# Regras resumidas para IA

- leia o CF-POS primeiro;
- use contexto mínimo;
- confirme a branch e a autorização recebida;
- trabalhe em branch própria por padrão; a `main` é permitida quando o proprietário autorizar explicitamente;
- autorização para editar a `main` não autoriza commit, push, deploy, migration ou tag;
- operações remotas exigem autorização específica;
- não amplie escopo;
- preserve invariantes;
- reporte comandos reais;
- atualize o handoff.
