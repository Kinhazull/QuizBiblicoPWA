# Ciclo de vida do desenvolvimento

## 1. Descoberta

- registrar problema ou ideia;
- verificar duplicidade;
- determinar impacto.

## 2. Análise

- localizar código relevante;
- confirmar estado atual;
- identificar invariantes;
- estimar risco.

## 3. Decisão

- escolher direção;
- registrar trade-offs;
- atualizar decisão formal se necessário.

## 4. Planejamento

- definir sprint;
- delimitar arquivos;
- proteger áreas sensíveis;
- definir critérios de aceite;
- definir testes;
- preparar rollback.

## 5. Implementação

- criar branch;
- executar Codex com prompt fechado;
- alterar somente o escopo.

## 6. Validação

- lint;
- build;
- testes proporcionais ao risco;
- revisão de diff;
- teste manual quando necessário.

## 7. Integração

- commit;
- push;
- PR;
- CI;
- revisão;
- squash merge.

## 8. Handoff

- atualizar estado;
- registrar histórico;
- registrar issues;
- definir próxima ação.
