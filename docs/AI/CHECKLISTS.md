# Checklists operacionais

## Antes da sprint

- [ ] `CURRENT_STATE.md` revisado
- [ ] branch definida
- [ ] objetivo único
- [ ] escopo delimitado
- [ ] critérios de aceite
- [ ] riscos
- [ ] testes
- [ ] rollback
- [ ] prompt do Codex pronto

## Antes do Codex

- [ ] contexto mínimo
- [ ] arquivos permitidos
- [ ] arquivos protegidos
- [ ] proibições explícitas
- [ ] formato do relatório final

## Antes do PR

- [ ] diff revisado
- [ ] lint
- [ ] build
- [ ] testes
- [ ] documentação
- [ ] sem segredos
- [ ] sem alterações fora do escopo

## Antes do merge

- [ ] CI concluída
- [ ] bloqueadores resolvidos
- [ ] aprovação humana
- [ ] rollback entendido
- [ ] handoff preparado

## Depois do merge

- [ ] branch removida
- [ ] `main` atualizada localmente
- [ ] `CURRENT_STATE.md` atualizado
- [ ] histórico atualizado
- [ ] próxima sprint registrada
