# Glossário

- **CF-POS:** Conte os Feitos Project Operating System.
- **Jornada:** ciclo competitivo do Quiz Bíblico.
- **Medalha:** prêmio competitivo ligado às Jornadas.
- **Conquista:** objetivo geral da plataforma.
- **Outbox:** tabela/fila transacional de eventos pendentes.
- **Consumer:** processador de um evento.
- **Dead letter:** evento que excedeu tentativas e exige análise.
- **Handoff:** resumo operacional para continuidade.
- **ADR/Decisão formal:** registro versionado de decisão relevante.
