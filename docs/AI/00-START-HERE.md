# CF-POS v1.0 — Comece aqui

O **Conte os Feitos Project Operating System (CF-POS)** é a memória operacional oficial do projeto.

## Ordem obrigatória de leitura

1. `AGENTS.md`
2. `PROJECT_CONTEXT.md`
3. `CURRENT_STATE.md`
4. `PROJECT_INDEX.md`
5. `CHAT_PROTOCOL.md`
6. Documentação específica da tarefa
7. Código estritamente necessário

## Regra principal

Não tente entender o repositório inteiro.

Use esta pasta para descobrir:

- o que está acontecendo;
- qual é a prioridade;
- quais regras não podem ser quebradas;
- quem executa cada ação;
- quais arquivos precisam ser lidos.

## Comando de retomada

> Leia `docs/AI/00-START-HERE.md` e siga a ordem obrigatória de leitura. Depois apresente o estado atual, o bloqueio prioritário, a próxima ação e quem deve executá-la. Não altere arquivos ainda.
